# 测试约定

适用范围：`tests/`。同时遵守根 `AGENTS.md` 和被测目录的说明。

- vitest 在 v2 副本中运行，使用真实 Cordis Schema 和可注入的本地 HTTP 测试服务。
- 固件只有中性文本和自行生成的测试文件，不访问或下载站点实际内容。
- 覆盖搜索、分类、详情、PDF/ZIP、缓存与并发、错误与取消、四个工具及 v2 配置控件。
- onebot-sandbox 验证使用独立测试空间，显式传 `spaceId`，同时检查私聊、群聊与 OneBot 文件动作；保留测试空间供复查，收尾停用机器人。
- 永不将测试 token、WebUI session 或后端密码写进测试源码及报告。
- 说明清单守卫检查所有子目录 `AGENTS.md` 都在根清单登记且存在。
